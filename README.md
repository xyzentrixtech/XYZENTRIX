## Overview

XYZENTRIX is a modern AI-powered business website built using React, Django, and PostgreSQL. It includes an intelligent business assistant (XAi), a dynamic company CMS, and a lead management system.

## Features

- AI Business Assistant (XAi)
- Company Profile CMS
- Contact Lead Management
- Responsive Design
- SEO Optimization
- Dynamic Company Information
- REST API Backend
- PostgreSQL Database
